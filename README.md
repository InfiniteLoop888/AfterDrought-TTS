# tts-afterdrought

酒馆扩展。从回复里抽出对白，交给本机语音网关，再播放返回的 WAV。

默认地址 `http://127.0.0.1:9881`，也就是 `AfterDrought/tts-api`。页面上的 **TTS** 按钮可以拖动，点开就是设置。以前如果地址还留着 `7860`，加载时会改到这个网关。

酒馆不在这台机器上时，语音网关填 `https://zzzbzhang.top/tts`，口令填代理的 `PROXY_TOKEN`。本机直连 9881 时口令留空。

扩展只发送角色和对白，不上传参考音频，也不带 IndexTTS 的原始参数：

```json
{
  "character_id": "甘雨",
  "text": "你、你怎么突然说这种话……",
  "emotion": { "type": "vector", "preset": "害羞", "vector": null, "weight": null }
}
```

角色名对上网关配置里的 id、显示名或别名。音色、默认情绪和说话习惯都在网关的 `characters/` 里。

正文里的 `[角色, 情绪]`、`【角色, 情绪】` 会就地换成语音。设置里的渲染有两种：

- **气泡**：标记换成语音条，这句话的原文留在后面。
- **台词**：这一句收成 `角色：「对白」`。点这句话播放，播放时整句高亮。

同一行末尾可以加导演指令，它不会被读出来，也不会留在台词里：

```text
[甘雨, 害羞] “你、你怎么突然说这种话……〖vd:{"delivery":{"intensity":"soft","pace":"gentle"}}〗”
```

指令不是合法 JSON，或情绪名不在允许范围内时，这句仍然按角色默认来合成。

设置里还有五组从播放器扩展收进来的功能：

- **提示词管理**：开关、注入深度、角色，以及可编辑的提示词。留空或点「恢复默认提示词」就用内置对白格式。内置格式带上网关的角色表和全部情绪名。表里的人用显示名；不在表里的人按剧情写全名。同一句里情绪明显变了才用行末 `〖vd:{"segments":[...]}〗` 分段，平时不要分段。自定义文本里 `{{CHAR}}` 是当前角色名，`{{CHARACTERS}}` 是角色表，`{{EMOTIONS}}` 是情绪列表。
- **播放与自动化**：气泡或台词、对白或全文、前端卡兼容、回复后自动合成、边生成边播放和起播缓冲。全文和兼容模式不改写正文。
- **酒馆通知**：只控制这个扩展自己的成功、警告和错误提示。
- **音频缓存**：同一句对白先查本机 IndexedDB。可以选目录导出、按清单或 `[角色]_文本_哈希.wav` 扫回来，也可以清空。
- **正则过滤**：抽对白之前按顺序替换。默认去掉 `<think>` 块。
