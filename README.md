# tts-afterdrought

酒馆扩展。从回复里抽出对白，交给本机语音网关，再播放返回的 WAV。

默认地址 `http://127.0.0.1:9881`，也就是 `AfterDrought/tts-api`。页面上的 **TTS** 按钮可以拖动，点开就是设置，不想要可以在设置里关掉悬浮窗。以前如果地址还留着 `7860`，加载时会改到这个网关。

酒馆不在这台机器上时，语音网关填 `https://zzzbzhang.top/tts`，口令填代理的 `PROXY_TOKEN`。本机直连 9881 时口令留空。

扩展只发送角色和对白，不上传参考音频，也不带 IndexTTS 的原始参数：

```json
{
  "character_id": "甘雨",
  "text": "你、你怎么突然说这种话……",
  "emotion": { "type": "vector", "preset": "害羞", "vector": null, "weight": null }
}
```

角色名对上网关配置里的 id、显示名或别名。音色、默认情绪和说话习惯都在网关的 `characters/` 里。

停止播放或切换聊天时，扩展会中止还在等的请求，并把它们的 `request_id` 发给 `POST /v1/tts/cancel`，让网关把排队中的合成一起撤掉。中止本身不算失败，不会弹红色错误。一次合成长于两分钟没有响应时，扩展会把这条标成可重试的错误，并撤回网关里的任务。

`request_id` 每次提交都换一个新的 UUID，和缓存键分开；取消请求按提交时记录的 `session_id` 分组，所以切到别的聊天之后撤回的仍是原来那个聊天里的任务。缓存键只负责找已有音频，不参与请求标识。

正文里的 `[角色, 情绪]`、`【角色, 情绪】` 会就地换成语音。设置里的渲染有两种：

- **气泡**：标记换成语音条，这句话的原文留在后面。光标停在语音条上能看到说话人和台词开头，长句不用点开也知道是哪句。
- **台词**：标记换成带引号的对白，不写人名。点这句话播放，播放时整句高亮；再点一次暂停，再点从暂停处接着播。键盘用 Tab 聚焦、Enter 或空格触发。长按或右键气泡还能「下载语音」「重新生成」「从这句继续」（把同一楼后面几句一起排队）。对白可以和旁白写在同一段里，每一句标记各自渲染，中间的旁白留在原文。同一句里换了情绪时，模型只写 `[角色]` 和导演块，页面把各段拼成这一句。

同一行末尾可以加导演指令，它不会被读出来，也不会留在台词里：

```text
[甘雨, 害羞] “你、你怎么突然说这种话……〖vd:{"delivery":{"intensity":"soft","pace":"gentle"}}〗”
```

指令不是合法 JSON，或情绪名不在允许范围内时，这句仍然按角色默认来合成。

设置面板分六页：**主要设置**、**播放**、**提示词**、**通知**、**缓存**、**过滤**。

- **主要设置**：总开关与渲染方式。气泡或台词、对白或全文、新回复自动朗读、回复后自动合成。「启用」是整个扩展的总开关，关掉后不再改写正文、不注入提示词、不合成语音，已渲染的语音条会还原成原文；「悬浮窗」只是页面右上角那个 TTS 按钮，关掉之后设置仍然可以从酒馆的扩展面板打开。全文同样渲染对白，朗读时按整条消息逐句读。「回复后自动合成」对「对白」范围无效——对白本来就会自动合成语音条，这个开关只在前端卡兼容或全文范围下起作用。
- **播放**：边生成边播放、起播缓冲句数、音量、语速、朗读时跟随滚动、电话/心声音效和前端卡兼容。缓冲越小起播越快、越容易断；语速 0.5 到 2 倍，改完从下一句生效，不会把正在播的句子掰断；跟随滚动只在这句不在视口里时才滚一下，不动用户自己的滚动位置。兼容模式不改写正文，只在前端卡上按整条消息读。播放走 WebAudio，下一句会提前解码好接上，句间没有重新解码的空档；浏览器不支持时才退回 `<audio>`，这时语速也照样生效，但音效链用不了。

  播放时左下角有一条迷你播放条：当前句的原文字幕、时间和进度，加上上一句、暂停、下一句、停止。空格暂停/继续，左右方向键换句，Esc 停止整条队列；焦点在输入框、设置面板或气泡上时不抢这些键。台词模式下当前句的底色会跟着进度铺开，气泡模式靠声波动画，不再叠进度。
- **电话 / 心声**：情绪写成 `电话·开心`、`心声：不安`、`电话里，冷淡` 时，`电话`/`心声` 只是播放音效的标记——电话走听筒滤波（砍掉低频和高频、中频顶出来、加一点粗糙），心声走贴耳的柔和滤波加小房间混响（带 2.6 秒尾巴，下一句会等回响散掉再接）。送给网关的情绪是标记词后面的部分，标记词不会进请求。设成「主要设置」里的默认情绪时，去掉标记词后回落到角色默认。想全关就在播放页关掉「电话/心声音效」。
- **提示词管理**：开关、注入深度、角色，以及可编辑的提示词。留空或点「恢复默认提示词」就用内置对白格式。内置格式带上网关的角色表和全部情绪名。表里的人用显示名；不在表里的人按剧情写全名。同一句里情绪换了就写 `[角色] 〖vd:{"segments":[...]}〗`，页面把各段拼成一句；平时不要分段。自定义文本里 `{{CHAR}}` 是当前角色名，`{{CHARACTERS}}` 是角色表，`{{EMOTIONS}}` 是情绪列表。
- **酒馆通知**：只控制这个扩展自己的成功、警告和错误提示。
- **音频缓存**：同一句对白先查本机 IndexedDB。缓存键带网关照角色列表给的 `voice_revision` 和 `synthesis_revision`，换参考音频或推理配置后旧缓存不再命中，聊天里已经渲染的语音条也会换成新键、丢掉旧音频，下次播放重新查缓存。导演块在算键之前先按键名排序，模型换个键序写同一份指令不会重复合成。导出目录里的文件按真实编码命名：`[角色]_[情绪]_文本_哈希.wav`（网关回 mp3/ogg 时后缀跟着变，按文件头判断，不再一律写 `.wav`），清单里同时记着情绪、导演块和音效。没有清单时按文件名扫回来，新名字能带回情绪和音效；页面上海挂着同一句时还会用它的缓存键，导演块不至于丢。旧版不带情绪那一段的名字也认。缓存最多保留 2000 条、400MB，超出后按最旧优先淘汰，浏览器配额不足时也会先清理再重试。也可以清空。注意键的口径改过一次（情绪去标记词、导演块排序），升级后第一遍可能不命中旧缓存，重新合成一次就回到稳态。
- **正则过滤**：抽对白之前按顺序替换。默认去掉 `<think>` 块。
