# tts-afterdrought

酒馆扩展。从回复里抽出对白，交给本机语音网关，再播放返回的 WAV。

默认地址 `http://127.0.0.1:9881`，也就是 `AfterDrought/tts-api`。页面上的 **TTS** 按钮可以拖动，点开就是设置，不想要可以在设置里关掉悬浮窗。以前如果地址还留着 `7860`，加载时会改到这个网关。

酒馆不在这台机器上时，语音网关填 `https://zzzbzhang.top/tts`，口令填代理的 `PROXY_TOKEN`。本机直连 9881 时口令留空。

扩展只发送角色和对白，不上传参考音频，也不带 IndexTTS 的原始参数：

```json
{
  "character_id": "甘雨",
  "text": "你、你怎么突然说这种话……",
  "emotion": { "type": "vector", "preset": "害羞", "vector": null, "weight": null }
}
```

角色名对上网关配置里的 id、显示名或别名。音色、默认情绪和说话习惯都在网关的 `characters/` 里。

停止播放或切换聊天时，扩展会中止还在等的请求，并把它们的 `request_id` 发给 `POST /v1/tts/cancel`，让网关把排队中的合成一起撤掉。中止本身不算失败，不会弹红色错误。一次合成长于两分钟没有响应时，扩展会把这条标成可重试的错误，并撤回网关里的任务。

`request_id` 每次提交都换一个新的 UUID，和缓存键分开；取消请求按提交时记录的 `session_id` 分组，所以切到别的聊天之后撤回的仍是原来那个聊天里的任务。缓存键只负责找已有音频，不参与请求标识。

正文里的 `[角色, 情绪]`、`【角色, 情绪】` 会就地换成语音。设置里的渲染有两种：

- **气泡**：标记换成语音条，这句话的原文留在后面。
- **台词**：标记换成带引号的对白，不写人名。点这句话播放，播放时整句高亮。对白可以和旁白写在同一段里，每一句标记各自渲染，中间的旁白留在原文。同一句里换了情绪时，模型只写 `[角色]` 和导演块，页面把各段拼成这一句。

同一行末尾可以加导演指令，它不会被读出来，也不会留在台词里：

```text
[甘雨, 害羞] “你、你怎么突然说这种话……〖vd:{"delivery":{"intensity":"soft","pace":"gentle"}}〗”
```

指令不是合法 JSON，或情绪名不在允许范围内时，这句仍然按角色默认来合成。

设置里还有五组从播放器扩展收进来的功能：

- **提示词管理**：开关、注入深度、角色，以及可编辑的提示词。留空或点「恢复默认提示词」就用内置对白格式。内置格式带上网关的角色表和全部情绪名。表里的人用显示名；不在表里的人按剧情写全名。同一句里情绪换了就写 `[角色] 〖vd:{"segments":[...]}〗`，页面把各段拼成一句；平时不要分段。自定义文本里 `{{CHAR}}` 是当前角色名，`{{CHARACTERS}}` 是角色表，`{{EMOTIONS}}` 是情绪列表。
- **播放与自动化**：气泡或台词、对白或全文、前端卡兼容、回复后自动合成、边生成边播放和起播缓冲。全文同样渲染对白，朗读时按整条消息逐句读。兼容模式不改写正文。「回复后自动合成」对「对白」范围无效——对白本来就会自动合成语音条，这个开关只在前端卡兼容或全文范围下起作用。「启用」是整个扩展的总开关，关掉后不再改写正文、不注入提示词、不合成语音，已渲染的语音条会还原成原文；「悬浮窗」只是页面右上角那个 TTS 按钮，关掉之后设置仍然可以从酒馆的扩展面板打开。
- **酒馆通知**：只控制这个扩展自己的成功、警告和错误提示。
- **音频缓存**：同一句对白先查本机 IndexedDB。缓存键带网关照角色列表给的 `voice_revision` 和 `synthesis_revision`，换参考音频或推理配置后旧缓存不再命中，聊天里已经渲染的语音条也会换成新键、丢掉旧音频，下次播放重新查缓存。导出写 `[角色]_文本_哈希.wav`，没有清单时按这个文件名扫回来，旧版不带方括号的名字也认。也可以清空。
- **正则过滤**：抽对白之前按顺序替换。默认去掉 `<think>` 块。
